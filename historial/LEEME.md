# Scripts históricos

Son los scripts que generaron las salidas originales de `evidencias/`. Cada uno se ejecutó desde la carpeta raíz del proyecto, con la configuración que existía en ese reto.

No sirven para repetir las pruebas: desde esta carpeta no encuentran el proyecto y, con la configuración final, algunos resultados serían distintos (por ejemplo, sin API Key ahora se obtiene 401). Para repetir las pruebas use `pruebas.cmd`.
